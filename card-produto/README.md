# Card de Produto

Projeto desenvolvido para praticar React e `styled-components`, com um card de produto responsivo e interativo.

## Recursos

- Estilos globais e estilos do componente separados com CSS-in-JS;
- Dados do produto recebidos por propriedades;
- Descrição expansível com `aria-expanded`;
- Botão de carrinho com texto e cor condicionais ao estado;
- Layout responsivo, de uma coluna em telas menores a duas colunas em telas maiores;
- Respeito à preferência de redução de movimento do sistema.

## Estrutura
